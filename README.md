# Симулятор протоколов квантового распределения ключей (КРК)

Программная модель для симуляции протоколов КРК на основе запутанных состояний.

## Что внутри
*   `core/` — базовая среда (квантовый канал, шумы, Ева, согласование).
*   `protocols/` — реализации протоколов (E91, BBM92, гибридный).
*   `tests/` — модульные и интеграционные тесты (28 тестов).
*   `app.py` — интерактивный веб-интерфейс (Streamlit).

## Требования
*   Python 3.13 или выше.
*   Операционная система: Windows, macOS или Linux.

## Как запустить (Windows)
1. Распакуйте архив в любую папку.
2. Дважды кликните по файлу `run.bat` (он создаст виртуальное окружение, установит зависимости и запустит браузер).

## Как запустить (вручную, для macOS/Linux или если run.bat не сработал)
Откройте терминал в папке с проектом и выполните по очереди:
```bash
python -m venv .venv
# Для Windows:
.venv\Scripts\activate
# Для macOS/Linux:
source .venv/bin/activate

pip install -r requirements-dev.txt
streamlit run app.py

## Как запустить (вручную, для macOS/Linux или если run.bat не сработал)
pytest -v
